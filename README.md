Hinário PAV
Lista dos louvores utilizados pela PAV SG.

Sobre
Este projeto reúne os louvores em uma página simples, acessível diretamente pelo navegador.

Acesso
O site publicado pode ser acessado pelo GitHub Pages:

https://vitorasdacosta.github.io/hinario-pav
Como usar
Acesse o endereço do projeto.
Navegue pela lista de louvores.
Use o navegador para pesquisar um louvor específico.
Contribuição
Sugestões e correções podem ser enviadas por meio de uma issue ou pull request.
